# QWE — Ultimate Debugging Suite (fork of Dark Dex)

QWE is a fork of the popular tool for debugging and exploring games on Roblox, Dark Dex.

⚠️ Important note
This project is a **fork** of Dark Dex and is not an official product. The original code was created by the author of Dark Dex and is distributed under the MIT license.
I (the author of this fork) do not claim authorship of the original code. My work consists of modifying it, adding new functionality, and fixing bugs.

🚀 usage
You can use the script via loadstring. Just run the following code in your executor:
```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/CharlloteSec/QWE/refs/heads/main/main.lua"))()
```
> [!TIP]
> The script will automatically update on the next run if you load it via `loadstring` — no need to download the file manually.
